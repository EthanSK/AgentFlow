Stay in flow with your agent

Speak, highlight, and screenshot without breaking your train of thought. Agent Flow weaves those moments into one message, in the order they happened.

Real-time context is included in Agent Flow source. Build it on your Mac to use it.

Using Codex? Install the Agent Flow context skill so it can read selections and screenshot paths alongside your speech, even across chats.

What stays in the flow

These are the parts Ethan actually uses—not a kitchen-sink model showcase.

01 · voice

Live words

GPT Live shows speech in the floating recorder. Stop once to paste the final result. Bring your own OpenAI API key.

02 · attention

Reading trail

Each separate highlight records what you were looking at—even when you didn't speak. Codex and Chrome add extra cues when available; other apps use a safe generic path.

03 · evidence

Screenshot cues

A screenshot joins the timeline as a purple path reference. Agent Flow doesn't upload its pixels; the receiving agent can open the file.

04 · delivery

Choose the input

Primary pastes into today's focused input. Next can pin the starting input or take a second chance while transcription runs. The two destination icons remain visible.

Selected text is context, not a command. Read-only capture never presses Copy or replaces your clipboard; protected or unreadable selections are left out.

Choose where each transcript goes

Map two mouse buttons: Primary to your Agent Flow recording shortcut, Next to macOS Next Track.

Primary while recording
Pastes into the input focused when the text arrives, like base VoiceInk.
Next while recording
Sends it back to the input where you started recording.
Next while transcribing, after a Primary stop
Second chance: sends it to the input focused when you press Next.

Only the Next routes save an exact input along with its app's Mode and auto-send. If Agent Flow can't verify that input, it shows an error instead of pasting somewhere else.

For Codex CLI or Claude Code, the terminal or editor hosting it owns the input, so set its Mode and auto-send there.

Also

  • Start a new recording while earlier ones are still transcribing.
  • The recorder shows on every connected monitor.
  • While recording, double-press Primary for a recoverable clipboard-only finish; triple-press to pause; press once while paused to resume. A fourth press in that same recording gesture pastes without auto-send.

Build from source

Bring your own OpenAI API key. Agent Flow calls OpenAI directly; there's no Agent Flow subscription or shared billing server.

git clone https://github.com/EthanSK/AgentFlow.git
cd AgentFlow
./scripts/install-first-use.sh
  • The first-use installer builds Agent Flow from public source, including real-time context, and puts it in your Applications folder.
  • Create an OpenAI API key and enable API billing. Add the key during setup; Agent Flow stores it in macOS Keychain and selects GPT Live for a fresh setup.
  • There is no public binary download or Agent Flow Homebrew cask yet. Building requires macOS 14.4 or later, full Xcode and Git. A local Parakeet model is installed as a fallback.
  • Use --all to also install the Codex context skill and YouTube helper. Chrome still needs its unpacked extension loaded manually.
  • Allow Microphone and Accessibility on first launch. Exact Terminal and iTerm delivery also needs Automation.
  • The script refuses an existing Agent Flow or legacy VoiceInk++ install; updates need a recording-idle check and rollback.
  • The upstream voiceink Homebrew cask installs VoiceInk, not Agent Flow.

More than talking

Ethan's extensions turn dictation into a live context stream. Install only the pieces you want.

Core · required
Agent Flow app, a transcription model, and macOS Microphone and Accessibility access.
Context · for Codex
Install the context skill to help Codex read speech, selections and screenshot paths together.
YouTube · optional
YouTube Bridge adds a menu app, Chrome native host and login LaunchAgent. You load its Chrome extension once.
Mouse · optional
Agentic Mouse and programmable buttons are separate. The Agent Flow keyboard shortcut works without them.

The full setup guide covers first install, manual permissions, Chrome loading and a real recording check. --all installs the bundled extras, not Agentic Mouse or your personal settings.

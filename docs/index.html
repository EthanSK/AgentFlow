Talk while you highlight and screenshot

VoiceInk++ is speech to text for Mac, built for working with agents. Highlight text in another app or take a screenshot mid-sentence; your final message puts a selected-text excerpt or screenshot path alongside the words you spoke.

Real-time context is included in VoiceInk++ source. Build it on your Mac to use it.

Using Codex? Install the VoiceInk++ context skill so it can read selections and screenshot paths alongside your speech, even across chats.

Choose where each transcript goes

Map two mouse buttons: Primary to your VoiceInk++ recording shortcut, Next to macOS Next Track.

Primary while recording
Pastes into the input focused when the text arrives, like base VoiceInk.
Next while recording
Sends it back to the input where you started recording.
Next while transcribing, after a Primary stop
Second chance: sends it to the input focused when you press Next.

Only the Next routes save an exact input along with its app's Mode and auto-send. If VoiceInk++ can't verify that input, it shows an error instead of pasting somewhere else.

For Codex CLI or Claude Code, the terminal or editor hosting it owns the input, so set its Mode and auto-send there.

Build from source

There's no public download or VoiceInk++ Homebrew cask. You need macOS 14.4 or later and full Xcode.

git clone https://github.com/EthanSK/VoiceInkPlusPlus.git
cd VoiceInkPlusPlus
./scripts/install-first-use.sh
  • The first-use installer builds VoiceInk++ from public source, including real-time context, and puts it in your Applications folder.
  • Use --all to also install the Codex context skill and YouTube helper. Chrome still needs its unpacked extension loaded manually.
  • Allow Microphone and Accessibility on first launch. Exact Terminal and iTerm delivery also needs Automation.
  • The script refuses an existing VoiceInk++ install; updates need a recording-idle check and rollback.
  • The upstream voiceink Homebrew cask installs VoiceInk, not VoiceInk++.

More than talking

Ethan's extensions turn dictation into a live context stream. Install only the pieces you want.

Core · required
VoiceInk++ app, a transcription model, and macOS Microphone and Accessibility access.
Context · for Codex
Install the context skill to help Codex read speech, selections and screenshot paths together.
YouTube · optional
YouTube Bridge adds a menu app, Chrome native host and login LaunchAgent. You load its Chrome extension once.
Mouse · optional
Agentic Mouse and programmable buttons are separate. The VoiceInk++ keyboard shortcut works without them.

The full setup guide covers first install, manual permissions, Chrome loading and a real recording check. --all installs the bundled extras, not Agentic Mouse or your personal settings.

Setup

No Agent Flow account or subscription. Transcribe on your Mac, or bring your own OpenAI API key for live words.

  1. Download, unzip, and move Agent Flow to Applications.
  2. Allow Microphone and Accessibility when asked, then pick your microphone. Screen Recording is only needed by the features that ask for it.
  3. Setup downloads NVIDIA's Parakeet model, so transcription works on your Mac without a key.
  4. For live words, add your own OpenAI API key with API billing; a ChatGPT subscription doesn't include API credit. You can use another provider's key for optional AI actions, or skip this step.

No API keys, private endpoints or personal settings are bundled. Your key stays in macOS Keychain, and providers bill you directly.

On an Intel Mac, use a cloud transcription provider with your own key, which bills you for usage. Local models aren't reliable on Intel; the on-device model is for Apple silicon.

Auto-send presses Return after pasting. It starts off; enable it per app in Modes if you want it. For Codex CLI or Claude Code, configure the terminal or editor it runs in.

Updates are manual: new versions are on GitHub releases. Agent Flow never replaces itself or installs upstream VoiceInk.

Optional extras
Context skill
Clone the source, then run python3 scripts/install-context-skill.py. It installs one shared copy for Codex and Claude Code and won't replace a skill you already have. The app never installs it for you.
YouTube Bridge
Pauses the playing video in Chrome when recording starts, then resumes only that video. YouTube keeps its own handling, and extension 0.2.6 adds standard video players on other sites. Some players can't be controlled. It asks to access all HTTP and HTTPS sites. Its helper and login LaunchAgent need a source checkout; you load the Chrome extension and approve its permissions yourself.
Chrome details
For page titles and addresses with highlights, enable Chrome's View → Developer → Allow JavaScript from Apple Events, then grant Agent Flow Automation access if asked.
Mouse controls
Map a mouse button to your recording shortcut if you want. Agentic Mouse is separate and isn't required.
VS Code
The Better Git bridge reads highlights in local code editors. Terminals and chat panels aren't covered.

Setup guide and app support

Controls

Use your keyboard shortcut or a mapped mouse button.

  • Press once to start, then again to stop. The text pastes into whichever input has keyboard focus when it arrives.
  • Press both Command and both Option keys together to start typing with the microphone off, then again to paste. Hold Shift as you finish to keep the result on your clipboard instead.
  • Press twice while recording to finish without pasting. The text stays on your clipboard and in History.
  • Press three times while recording to pause, then once to resume. The recorder's pause button does the same.
  • Start another recording while the last one is still transcribing.
  • History keeps your results. A double-press finish saves the recording's audio and live words first, so you can replay, copy or retranscribe it.
Next Track key

While the recorder is visible, Next Track won't skip music. Capturing the input where you started is off in this release, so pressing it while recording does nothing.

After a normal stop, while the result is still transcribing, one press sends it to the input focused at that moment instead, using that app's settings. If Agent Flow can't verify that input, it shows an error rather than pasting somewhere else.

Build from source

Needs macOS 14.4 or later, Xcode and Git.

git clone https://github.com/EthanSK/AgentFlow.git
cd AgentFlow
./scripts/install-first-use.sh
  • Builds Agent Flow, installs it in ~/Applications and opens it. It won't replace an existing installation, including a downloaded app.
  • On a first install, add --all to also install the context skill and YouTube helper. Chrome still needs its unpacked extension loaded and approved by hand.
  • Already using the download? Run only python3 scripts/install-context-skill.py from the checkout to add the skill.
  • The upstream voiceink Homebrew cask installs VoiceInk, not Agent Flow.

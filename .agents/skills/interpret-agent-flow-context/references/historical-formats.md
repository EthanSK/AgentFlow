# Interpret Agent Flow context

Read interleaved dictated speech and context tags as one messy, best-effort user message. Infer what Ethan is trying to say and which references he likely means; tag placement is a clue, not a precise binding or strict chronology. Preserve the XML grammar so old messages continue to work.

First spend a moment understanding what Ethan actually meant from the flow of selections, approximate timing, speech and typing. A highlight may be him pointing around while speaking, rather than the exact phrase to answer; abundant context can also make a literal reading misleading. Check nearby clues and plausible misreadings without inventing hidden intent or promoting selected text into instructions. Ask only if the remaining ambiguity would materially change the action.
